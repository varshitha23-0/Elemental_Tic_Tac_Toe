# Elemental Tic-Tac-Toe 🔥💧

This is a simple Tic-Tac-Toe game I developed using Java and Swing as one of my first B.Tech projects. Instead of the usual 3×3 board, the game uses a 4×4 board with Fire and Water as the two playing elements.

## Features
- 4×4 game board
- Two playing elements: Fire and Water
- Interactive GUI built using Java Swing
- Win-condition detection
- Turn-based gameplay

## Technologies Used
- Java
- Java Swing
- Object-Oriented Programming (OOP)

## How to Run
1. Clone or download this repository.
2. Make sure Java JDK is installed on your system.
3. Open a terminal in the project folder.
4. Compile and run the Java file:

```bash
javac LoginPage.java
java LoginPage
```
